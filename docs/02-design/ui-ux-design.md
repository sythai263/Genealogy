# UI/UX Design Document

## 1. Design Principles

### 1.1 Core Principles

| Principle | Description |
|-----------|-------------|
| **Simplicity** | Giao diện đơn giản, dễ sử dụng cho mọi lứa tuổi |
| **Clarity** | Thông tin rõ ràng, hierarchy tốt |
| **Accessibility** | WCAG 2.1 AA compliant, elderly-friendly |
| **Mobile-first** | Responsive, touch-friendly |
| **Vietnamese** | 100% tiếng Việt, phù hợp văn hóa |

### 1.2 Target Users

| User | Age | Tech Level | Primary Device | Needs |
|------|-----|------------|----------------|-------|
| **HĐGT (Admin)** | 50-70 | Low-Medium | Desktop/Tablet | Quản lý, nhập liệu |
| **Thành viên** | 30-60 | Medium | Mobile | Tra cứu, xem tree |
| **Thế hệ trẻ** | 18-35 | High | Mobile | Explore, share |

```
Tree View Specific:
- Mobile: Horizontal scroll, simplified nodes
- Tablet: Full tree, touch-friendly zoom
- Desktop: Full tree, mouse interactions, minimap
```

## 7. Accessibility (A11y)

### 7.1 Requirements

| Requirement | Implementation |
|-------------|----------------|
| **Keyboard navigation** | Tab order, focus indicators |
| **Screen readers** | ARIA labels, semantic HTML |
| **Color contrast** | WCAG AA (4.5:1 for text) |
| **Font sizing** | Respects user preferences, min 16px |
| **Touch targets** | Min 44x44px for mobile |
| **Reduced motion** | Respects prefers-reduced-motion |

### 7.2 Elderly-Friendly Features

| Feature | Implementation |
|---------|----------------|
| **Large text option** | Toggle in settings |
| **High contrast mode** | Dark backgrounds, light text |
| **Simple navigation** | Clear labels, minimal depth |
| **Large buttons** | h-12 (48px) option |
| **Clear error messages** | Vietnamese, helpful |
